# 🏅 Juegos Asocomunales de Sabaneta 2026

Plataforma oficial para la gestión deportiva, programación de encuentros (lugar y hora), inscripciones, carnets con tallas de uniformes, fixture y cuadro de honor de los **Juegos Asocomunales de Sabaneta 2026** (ASOCOMUNAL & INDESA Sabaneta).

## 📋 Estructura y Módulos de la Plataforma

1. **1. Inicio (Tablero General)**:
   - Resumen institucional, métricas en tiempo real (357 deportistas, 71 planillas, 19 JACs).
   - Acceso directo a los módulos principales.
   - Cronograma y Sedes Oficiales Sabaneta 2026 por modalidades (Deportes de Conjunto, Tradicionales e Individuales).

2. **2. Medallería (Podio & Clasificación)**:
   - Podio de Honor Olímpico (🥇 Oro, 🥈 Plata, 🥉 Bronce).
   - Tabla general de posiciones con las 19 Juntas de Acción Comunal.
   - Controles interactivos (+ / -) para actualizar medallas al instante.
   - Filtros por sector (Urbano / Rural), ordenamiento olímpico y exportación a Excel e impresión.

3. **3. Programar (Lugar y Hora de Competencia)**:
   - Centro de asignación de canchas/escenarios, fechas y horas por cada deporte.
   - Edición rápida de horarios, marcadores y estados (Pendiente, En Vivo, Finalizado).
   - Impresión de boletines oficiales de programación para entrega física a delegados.

4. **4. Inscripciones & Planillas**:
   - 71 planillas oficiales consolidadas por deporte, rama y JAC.
   - Censo general de 357 deportistas con tallas de uniformes, EPS, contacto y vecindad comunal.
   - Carnets oficiales de competencia listos para imprimir con código QR.
   - Formulario de inscripción y registro de nuevos deportistas y equipos.

5. **5. Por Deporte (Resultados)**:
   - Fixture detallado y seguimiento específico por disciplina deportiva (Baloncesto, Fútbol de Salón, Voleibol, Dominó, Tejo, Rana, Billar, Ajedrez, Atletismo, Danza Folclórica, etc.).

6. **6. Por Junta Comunal (JAC)**:
   - Agenda y partidos exclusivos por cada uno de los 19 barrios y veredas de Sabaneta.

## 🛠️ Comandos de Desarrollo y Despliegue

### 1. Iniciar en entorno de desarrollo local:
```bash
npm run dev
```

### 2. Compilar para producción:
```bash
npm run build
```

### 3. Desplegar automáticamente a GitHub Pages:
```bash
npm run deploy
```
*Este comando compila el proyecto y actualiza la rama `gh-pages` en GitHub de forma automática.*
